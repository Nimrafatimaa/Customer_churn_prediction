# Customer Churn Prediction | Machine Learning

## Project Overview
Developed a machine learning classification project to predict customer churn using the IBM Telco Customer Churn dataset.

The project identifies customers who are likely to discontinue their telecom services, helping businesses understand customer retention patterns.

## Objectives
- Perform exploratory data analysis (EDA).
- Clean and preprocess customer data.
- Handle missing values and categorical variables.
- Perform feature selection.
- Train and compare multiple classification models.
- Evaluate model performance.
- Predict churn probability for new customers.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Joblib

## Machine Learning Algorithms
1. Logistic Regression
2. Decision Tree Classifier
3. Random Forest Classifier

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

## Dataset
IBM Telco Customer Churn Dataset – 7,043 customer records and 21 columns.

## Project Workflow
1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. Feature Engineering and Selection
5. Data Preprocessing
6. Model Training
7. Model Evaluation
8. Model Saving
9. New Customer Prediction

## Results
Model performance is compared using accuracy, precision, recall and F1-score. The best-performing model is selected based on F1-score.

## Business Impact
The model can help telecom companies identify customers at risk of leaving and prioritize customer retention strategies.
